# Installation:
---
- git is a prerequisite! install git first...
- also install the packages required for the installation of neovim, and tmux also(with all the dependencies)
- install also: stow for dotfiles management

git clone https://github.com/uday1402/dotfiles.git ~/dotfiles

cd ~/dotfiles

- run the install script from inside the dotfiles directory only:

./install.sh

# Changing Dotfiles:
---
- the dotfiles will be present in their expected path, with the help of dotfiles
- whenever you want to change the dotfiles, change DIRECTLY from the source file

after making the changes:
- cd into dotfiles dir and add, commit and push the changes
